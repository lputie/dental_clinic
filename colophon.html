Tools and approach

This website was created as a local HTML project for Introduction to Web Technologies. It uses plain HTML without CSS, JavaScript, frameworks, templates or a site builder. The pages are opened directly from the computer, so no domain or hosting is required.

The real organization studied is Elite Dental Astana. Its public website was examined as the real-page sourceclinic for Task A. The original site uses many generic <div> elements together with external styling and scripts. This project intentionally uses semantic HTML such as <header>, <nav>, <main>, <section>, <article> and <footer>.

Task B: What a web page is made of

A web page is a document containing structured content and instructions that a browser can interpret. In this project, the HTML file contains a document type declaration, metadata in the head, and visible content in the body. The browser reads the HTML, creates a document structure from the elements, and displays text, links, images and forms according to their meaning. The browser can open these files directly because this assignment uses local HTML documents.

In my own files I chose semantic tags instead of generic divs in several important places. I used <nav> for page navigation because its purpose is navigation. I used <section> for groups such as the clinic profile because each group has its own topic and heading. I used <article> for self-contained descriptions because those pieces can be understood as separate information units.

When a visitor presses the submit button today, nothing is sent to the clinic because there is no server-side handler behind the local project. The browser validates the form fields and then follows the form's action according to the HTML configuration. A future version could connect the form to a real server.
