How this site was made

Tools and approach

This website was created as a local HTML project for Introduction to Web Technologies. It uses plain HTML without CSS, JavaScript, frameworks, templates or a site builder. The pages are opened directly from the computer, so no domain or hosting is required.

The real organization studied is Elite Dental Astana. Its public website was examined as the real-page source for Task A. The original site uses many generic <div> elements together with external styling and scripts. This project intentionally uses semantic HTML such as <header>, <nav>, <main>, <section>, <article>, <aside> and <footer>.

Task B: What a web page is made of

My explanation

A web page is a document containing structured content and instructions that a browser can interpret. In this project, the HTML file contains a document type declaration, metadata in the head, and visible content in the body. The browser reads the HTML, creates a document structure from the elements, and displays text, links, images, tables and forms according to their meaning. The browser can open these files directly because this assignment uses local HTML documents.

In my own files I chose semantic tags instead of generic divs in several important places. I used <nav> for page navigation because its purpose is navigation. I used <section> for groups such as the clinic profile because each group has its own topic and heading. I used <article> for self-contained descriptions because those pieces can be understood as separate information units.

When a visitor presses the submit button today, nothing is sent to the clinic because there is no server-side handler behind the local project. The browser validates the form fields and then follows the form's action according to the HTML configuration. A future version could connect the form to a real server.

Semantic HTML choices

Why semantic elements were used

The <header> contains introductory site information and navigation. The <main> contains the primary content of each page. The <section> element separates major topics, while <article> is used for information that can stand as an independent unit.

The <aside> element is used for additional information related to the main content, such as contact information. The <footer> contains contact details and copyright information.

Task A observations

Structural comparison

The real clinic website was used as the comparison source. One structural difference is that a website created with a visual website builder may contain many generic containers. In this project, semantic elements are used where their meaning is clear.

A second difference is that this student project avoids unnecessary styling and scripts because the assignment requires clean HTML. A third difference is that the project deliberately uses explicit document structure, making the relationship between header, navigation, main content and footer easy to identify.
